# 01 硬件与引脚

遥控器板，本文所有引脚均与原理图逐脚核对。

## 1. 主控与供电

| 项目 | 配置 |
|---|---|
| 芯片 | STM32F103C8T6（LQFP48，Cortex-M3） |
| 晶振 | **无外部晶振**，`OSC_IN` / `OSC_OUT` 空悬，纯内部 HSI 起振 |
| 系统时钟 | HSI 8 MHz ÷ 2 = 4 MHz，PLL ×12 = **48 MHz** |
| 总线 | HCLK 48 MHz，APB2 48 MHz，APB1 24 MHz（`TIM3CLK` = 48 MHz） |
| Flash 等待周期 | 2（`FLASH_Latency_2`），预取缓冲开启 |
| 供电 | 单节锂电池 → MIC5219 LDO → 3.3 V |
| SRAM | 20 KB，其中 FreeRTOS `heap_4` 占 8 KB |

不用 HSE 是成本与体积取舍。代价是 HSI 精度只有 ±1%（全温 ±3%），1 kHz 硬件时基和 100 Hz 组帧周期都会带这个偏差，但对遥控链路无实质影响。

## 2. 中断优先级

NVIC 分组 `Group4`。

| 中断源 | 抢占优先级 | 说明 |
|---|---|---|
| `TIM3` | 6 | 1 kHz 累加毫秒计数，不调用 RTOS API |
| `SVC` | 0 | `vTaskStartScheduler()` 启动首个任务时触发一次 |
| `SysTick` / `PendSV` | 15 | FreeRTOS 内核，1 kHz |

| 按键 AUX2 | `PB11` | `IPU` | |
| 按键 AUX3 | `PC14` | `IPU` | |
| 按键 AUX4 | `PC15` | `IPU` | |
| 微调 左 / 右 | `PA6` / `PA7` | `IPU` | Roll −5 / +5 |

## 4. ADC + DMA

| 项目 | 配置 |
|---|---|
| 模式 | ADC1 独立、4 通道扫描、连续转换、右对齐 |
| 采样时间 | 55.5 周期 |
| ADC 时钟 | `PCLK2 / 8` = 6 MHz |
| DMA | `DMA1_Channel1` 循环模式，外设地址固定、内存自增，半字宽度 |
| 上电动作 | 硬件校准后软件触发一次，此后后台自动刷新 |

`ADC_ConvertedValue[4]` 由 DMA 持续覆写，上层只做快照读取。

## 5. TIM3 硬件毫秒时钟

| 参数 | 值 |
|---|---|
| 输入时钟 | `TIM3CLK` = 2 × PCLK1 = 48 MHz |
| PSC | 47 → 计数频率 1 MHz |
| ARR | 999 → 更新频率 1 kHz |

SysTick 归 FreeRTOS 独占（1 ms 节拍），TIM3 是独立的硬件毫秒基准，`delay_ms()` 与 NRF 发送超时都用它。进入任务后一律改用 `vTaskDelay` / `vTaskDelayUntil`。

## 6. NRF24L01+

| 寄存器 | 值 |
|---|---|
| `TX_ADDR` / `RX_ADDR_P0` | `{0xE1, 0xE2, 0xE3, 0xE4, 0xE5}` |
| `EN_AA` | `0x00`（关闭自动应答） |
| `EN_RXADDR` | `0x01` |
| `SETUP_RETR` | `0x1A` |
| `RF_CH` | 1（2401 MHz） |
| `RF_SETUP` | `0x07`（1 Mbps / 0 dBm） |
| `CONFIG` | `0x0E`（PWR_UP + CRC16 + PRIM_TX） |

发送流程：拉低 CE → 写 32 字节 TX FIFO → 拉高 CE → 等 IRQ 拉低，软件超时 5 ms。超时或异常时拉低 CE、清 TX FIFO、清状态位后返回，绝不死等。

上电自检通过向 `TX_ADDR` 写 5 字节 `0xA5` 再回读比对，最多 20 次、每次间隔 50 ms。

**与飞控端必须完全一致**：频道、地址、速率、载荷长度、无应答、CRC16。

## 7. AT24C02 EEPROM

| 项目 | 配置 |
|---|---|
| 器件写地址 | `0xA0` |
| Roll 微调 | `0x00 ~ 0x01`（小端 int16） |
| Pitch 微调 | `0x04 ~ 0x05` |
| 自检测试字节 | `0x55` |
| 页写等待 | 10 ms（手册最大 5 ms，留 2 倍裕量） |

上电读回后做合法性校验：必须在 `[-250, +250]` 内且为 5 的整数倍，否则归零。这条规则会拦下全新芯片出厂值 `0xFFFF`（解读为 −1）。

## 8. 摇杆与通道映射

两个双轴 5 K 电位器，滑动端直接接 ADC 输入，供电 3.3 V。

| 通道 | ADC 索引 | 映射 |
|---|---|---|
| Yaw | 0 | `1000 + 0.25 × ADC` |
| Throttle | 1 | `1000 + 0.20 × ADC` |
| Pitch | 2 | `1000 + 0.25 × ADC + 微调` |
| Roll | 3 | `1000 + 0.25 × ADC + 微调` |

结果经一阶低通（新值权重 0.25）后钳位到 `[1000, 2000]`。

油门用 0.20 而摇杆用 0.25 是有意为之：飞控端定高模式的油门死区上限是 1750，0.20 对应约 92% 行程，0.25 会让常见悬停杆位被误判成持续爬升。**这个系数不能改。**
