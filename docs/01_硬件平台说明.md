# 01 遥控器硬件平台与外设说明

> 本文档完整记录 Cloud-Drone-Remote（发送端）的芯片时钟树、引脚分配、外设配置与中断优先级规划，
> 与当前 FreeRTOS 多任务版源码逐行核对一致。

---

## 1. 主控芯片与时钟树

| 项目 | 规格 / 配置 |
| :--- | :--- |
| 芯片型号 | STM32F103C8T6（ARM Cortex-M3） |
| 存储资源 | Flash 64 KB（`0x08000000`），SRAM 20 KB（`0x20000000`） |
| 晶振方案 | **无外部晶振**（低成本低功耗设计，纯内部 HSI 起振） |
| 系统主频 | **48 MHz**：`HSI (8 MHz) ÷ 2 × PLL12` |
| 总线频率 | `SYSCLK = 48 MHz`，`HCLK(AHB) = 48 MHz`，`PCLK2(APB2) = 48 MHz`，`PCLK1(APB1) = 24 MHz` |
| 定时器时钟 | APB1 预分频 = `/2`（≠1），按 STM32F10x 规则自动 ×2 → **`TIM3CLK = 48 MHz`** |
| ADC 时钟 | `PCLK2 / 8 = 6 MHz`（低于 14 MHz 规格上限） |
| NVIC 分组 | `NVIC_PriorityGroup_4`（4 位抢占优先级，0 位子优先级，FreeRTOS 必需） |

> `system_stm32f10x.c` 已定义 `SYSCLK_FREQ_48MHz`，`SystemCoreClock` 与 `RCC_Configuration()` 配置的真实主频一致，FreeRTOS 的 `configCPU_CLOCK_HZ` 直接引用 `SystemCoreClock`。

## 2. 引脚分配总表

| 外设模块 | 引脚 | 模式 | 说明 |
| :--- | :--- | :--- | :--- |
| **4 路摇杆 ADC1** | `PA0` = Yaw、`PA1` = THR、`PA2` = Pitch、`PA3` = Roll | `GPIO_Mode_AIN` | DMA1_CH1 循环采集，12 位（0~4095） |
| **NRF24L01+ 软件 SPI** | `PB13` = SCK、`PB15` = MOSI、`PB14` = MISO | 推挽输出 / 浮空输入 | SPI Mode 0（CPOL=0, CPHA=0） |
| **NRF24L01+ 控制脚** | `PB12` = CSN、`PA11` = CE、`PA8` = IRQ | 推挽输出 / 上拉输入 | IRQ 低电平有效，发送完成拉低 |
| **AT24C02 软件 I2C** | `PB6` = SCL、`PB7` = SDA | `GPIO_Mode_Out_OD` | 开漏输出，板载外部上拉电阻，器件地址 `0xA0` |
| **蜂鸣器** | `PA12` | `GPIO_Mode_Out_PP` | **高电平响（`BEEP_ON` / `BSRR`），低电平停（`BEEP_OFF` / `BRR`）** |
| **功能按键 AUX1~4** | `PA15`、`PB11`、`PC14`、`PC15` | `GPIO_Mode_IPU` | 内部上拉，按下接地为低电平 |
| **微调按键 左 / 右** | `PA6`、`PA7` | `GPIO_Mode_IPU` | Roll 中位 -5 / +5（限幅 ±250） |
| **微调按键 前 / 后** | `PB0`、`PB1` | `GPIO_Mode_IPU` | Pitch 中位 -5 / +5（限幅 ±250） |
| **SWD 调试口** | `PA13` (SWDIO)、`PA14` (SWCLK) | 复用 | 关闭 JTAG（`GPIO_Remap_SWJ_JTAGDisable`）以释放 `PA15` |

## 3. 各外设配置详情

### 3.1 ADC1 + DMA1（`src/driver/adc.c`）
- 独立模式、4 通道扫描 + 连续转换、数据右对齐、采样周期 `55.5 Cycles`。
- `DMA1_Channel1` 循环模式自动刷新 `ADC_ConvertedValue[4]`：
  - `ADC_CH_YAW (0)` → `PA0`
  - `ADC_CH_THR (1)` → `PA1`
  - `ADC_CH_PITCH (2)` → `PA2`
  - `ADC_CH_ROLL (3)` → `PA3`
- 上层通过 `ADC1_ReadSnapshot()` 获取一致性快照，CPU 无需等待转换。

### 3.2 TIM3 硬件毫秒时钟（`src/driver/tim.c` + `src/core/delay.c`）
- SysTick 归 FreeRTOS 内核独占（1kHz）；硬件毫秒计数 `SysTick_count` 由 TIM3 独立维护。
- 配置参数：`TIM3CLK = 48 MHz`，`PSC = 47`（48 分频 → 1 MHz），`ARR = 999`（1000 计数 → **精确 1 kHz / 1 ms**）。
- 使用边界：`delay_ms()` 仅限调度器启动前的硬件初始化阶段；进入 FreeRTOS 任务后一律使用 `vTaskDelay()` / `vTaskDelayUntil()`，`get_ms_tick()` 可安全用于超时判定（如 NRF 发送 5ms 超时）。

### 3.3 NRF24L01+ 无线模块（`src/bsp/nrf24l01.c`）
- 工作模式：**单向 TX 模式**，32 字节载荷，`RF_CH = 1`，地址 `{0xE1,0xE2,0xE3,0xE4,0xE5}`，1Mbps / 0dBm，`EN_AA = 0`（无 ACK），CRC16。
- 上电检测：`NRF24L01_init()` 最多重试 20 次（每次间隔 50ms，总窗口 1s）；失败置位 `FAULT_NRF` 后继续启动并报警，不死等。
- 发送超时与自愈：`NRF24L01_TxPacket()` 等待 IRQ 拉低带 **5ms 软件超时**，超时自动拉低 CE、执行 `FLUSH_TX` 并清 `STATUS`；若连续 20 次超时（200ms），`Task_RC_Tx` 自动复查在位并尝试 `TX_Mode()` 恢复，离线则置位 `FAULT_NRF`。

### 3.4 AT24C02 EEPROM（`src/driver/i2c.c` + `src/bsp/eeprom.c`）
- 存储地址布局（与历史固件完全兼容）：
  - `0x00 ~ 0x01`：Roll 微调值（`int16_t`，小端 2 字节）
  - `0x04 ~ 0x05`：Pitch 微调值（`int16_t`，小端 2 字节）
  - `0x55`：上电自检测试字节（写 `0xAA` 等 20ms 读回比对）
- 上电自检最多重试 20 次，失败置位 `FAULT_EEPROM` 并清零微调。
- 合法性过滤：上电读回值必须满足 `[-250, +250]` 且为步进 5 的整数倍，自动拦截全新芯片出厂 `0xFFFF (-1)` 或脏数据。
- 运行期由 `Task_Storage` 独占异步写入，采用 `vTaskDelay(10ms)` 等待页写周期并执行写后回读校验。

### 3.5 独立看门狗 IWDG（`src/app/task_monitor.c`）
- 时钟源：内部 LSI（标称 40 kHz）；预分频 `128`（计数频率 `312.5 Hz`），重载值 `800` → **超时约 2.56 秒**。
- `main.c` 开启 `DBGMCU_Config(DBGMCU_IWDG_STOP, ENABLE)`，仿真器断点暂停时自动冻结看门狗。
- 仅当 `Task_Monitor` 确认 `Task_RC_Tx` 与 `Task_Input` 在 500ms 窗口内均上报心跳时才喂狗，任何核心任务死锁均会在 ~2.56s 内硬件复位恢复（快于飞控端 5s 失联门限）。

## 4. 中断优先级规划表（NVIC Group4）

| 中断源 | 抢占优先级 | 是否调用 FreeRTOS API | 说明 |
| :--- | :---: | :---: | :--- |
| `TIM3_IRQHandler` | **6** | 否 | 1kHz 累加 `SysTick_count`，高于内核中断保证硬件时钟精度 |
| `configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY` | **5** | — | FreeRTOS 可管理的最高中断优先级分界线（数值 ≥5 才允许调用 `FromISR` API） |
| `SysTick_Handler` | **15** | 是（内核） | FreeRTOS 1kHz 调度节拍 |
| `PendSV_Handler` | **15** | 是（内核） | FreeRTOS 任务上下文切换 |
| `SVC_Handler` | **0** | 是（内核） | 仅在 `vTaskStartScheduler()` 启动首个任务时触发一次 |
