# 01 遥控器硬件平台说明（FreeRTOS 升级参考）

> 本文档描述遥控器（发送端）的硬件组成、引脚分配、外设配置与调度时序，
> 供 FreeRTOS 版与飞控端联调维护时参考。
>
> 数据来源：`remote.uvprojx`、`src/driver/`、`src/bsp/`、`src/control/`、`src/core/` 源码逐行核对。

---

## 1. 主控芯片与时钟

| 项目 | 内容 |
|---|---|
| 型号 | STM32F103C8T6（Cortex-M3） |
| 主频 | **48 MHz（HSI 内部时钟）**：HSI 8MHz ÷ 2 × PLL12 |
| Flash | 64 KB（IROM `0x08000000`，`0x10000`） |
| RAM | 20 KB（IRAM `0x20000000`，`0x5000`） |
| 晶振 | **无外部晶振**（低成本设计，`SystemInit` 仅使能 HSI） |
| 时钟树 | SYSCLK=48M，AHB=48M，APB1=24M，APB2=48M |
| 中断分组 | `NVIC_PriorityGroup_4`（FreeRTOS 要求 4 位抢占优先级） |

> 注意：遥控器主频 48MHz 由 `RCC_Configuration()`（`src/core/init.c`）配置
> （HSI 8MHz÷2 × PLL12）；`system_stm32f10x.c` 已定义 `SYSCLK_FREQ_48MHz`，
> `SystemCoreClock` 与真实主频一致，FreeRTOS 的 `configCPU_CLOCK_HZ` 直接使用它。

## 2. 引脚分配总表

| 外设 | 引脚 | 说明 |
|---|---|---|
| ADC1（DMA 循环） | PA0 = Yaw，PA1 = THR，PA2 = Pitch，PA3 = Roll | 4 通道摇杆，DMA1_CH1 循环采集 |
| NRF24L01 SPI（软件模拟） | PB13 = SCK，PB14 = MISO，PB15 = MOSI | 专用 |
| NRF24L01 控制 | PB12 = CSN，PA11 = CE，PA8 = IRQ | IRQ 输入上拉，发送后等待拉低 |
| 蜂鸣器 | PA12 | 低电平响（`BEEP_H`） |
| 按键 AUX1~AUX4 | PA15、PB11、PC14、PC15 | 输入上拉，按下为低 |
| 按键 微调 左/右 | PA6、PA7 | Roll 微调 ±5/次，写 EEPROM |
| 按键 微调 前/后 | PB0、PB1 | Pitch 微调 ±5/次，写 EEPROM |
| 软件 I2C | PB6 = SCL，PB7 = SDA | 挂 AT24C02 EEPROM |
| USART1（预留调试） | PA9 = TX，PA10 = RX | 115200-8N1，当前未启用 |
| SWD 调试 | 复用 AFIO->MAPR=0x02000000 | 释放 JTAG，仅保留 SWD |

## 3. 各外设配置详情

### 3.1 ADC + DMA（`src/driver/adc.c`）
- ADC1 独立模式、扫描 + 连续转换、右对齐，4 通道（CH0~CH3）采样 55.5 周期。
- DMA1_Channel1 循环模式，`ADC_ConvertedValue[4]` 自动刷新：
  `[0]=Yaw(PA0)`、`[1]=THR(PA1)`、`[2]=Pitch(PA2)`、`[3]=Roll(PA3)`。
- ADC 时钟 = PCLK2/8 = 6MHz。

### 3.2 NRF24L01（`src/bsp/nrf24l01.c`）
- 工作模式：**TX 模式**，32 字节载荷，1Mbps，0dBm（`RF_SETUP=0x07`）。
- RF 通道：`RF_CH = 1`；地址 `{0xE1,0xE2,0xE3,0xE4,0xE5}`（与飞控端 RX 一致）。
- `EN_AA = 0`（无自动应答），`CONFIG = 0x0E`（PWR_UP + CRC16，PRIM_TX）。
- 发送流程：写 `WR_TX_PLOAD` → CE 拉高 → 等待 IRQ 拉低 → 读 STATUS，
  `MAX_TX` 时清 FIFO。**无超时保护**，与旧版行为一致。

### 3.3 软件 I2C + AT24C02（`src/driver/i2c.c` + `src/bsp/eeprom.c`）
- 软件模拟 I2C，PB6/PB7 开漏输出，器件地址 `0xA0`。
- 存储：Roll 微调（地址 0）、Pitch 微调（地址 4），各 2 字节。
- 上电 `test_AT24C02()` 自检（写 0x55→0xAA 读回），失败则死等。
- 写操作含 `delay_ms(10)` 等待 EEPROM 内部写周期。

### 3.4 蜂鸣器（`src/core/init.c`）
- PA12 推挽输出，低电平响。
- 上电短暂提示音（约 1.6 亿次空循环，约 3.5s@48MHz）。
- 按键动作反馈、系统异常（堆栈溢出/内存分配失败）长鸣。

### 3.5 USART1（预留，`src/driver/usart.c`）
- 115200-8N1，RXNE 中断 + 测试发送。
- 当前 `ALL_Init()` 未调用 `USART1_Config()`，保留驱动备用。

## 4. 实时调度时序（FreeRTOS 版本）

> 与旧版裸机（SysTick 中断内分频调度）行为一致，仅改为任务调度。

| 周期 | 位置 | 内容 |
|---|---|---|
| 1 ms | TIM3_IRQHandler | `SysTick_count++`（毫秒时钟，SysTick 归 FreeRTOS） |
| 1 ms | FreeRTOS SysTick | 内核节拍（configTICK_RATE_HZ=1000） |
| 10 ms | RCTask（优先级3） | `RC_Analy()`：采集滤波 → 按键扫描 → NRF 组帧发送 |

主循环结构（`src/core/main.c`）：

```c
NVIC_PriorityGroupConfig(NVIC_PriorityGroup_4);   // FreeRTOS 要求 4 位抢占优先级
RCC_Configuration();                              // HSI PLL 48MHz
cycleCounterInit();                               // TIM3 1kHz 毫秒时钟
ALL_Init();                                       // 硬件初始化（调度器启动前）
xTaskCreate(RCTask, "rc", 128, NULL, 3, NULL);
vTaskStartScheduler();
```

中断优先级（Group4）：TIM3=6（毫秒时钟，不调 API）> SysTick/PendSV=15（内核）。
FreeRTOS 堆 8KB（heap_4），任务栈：遥控 128 字、空闲 128 字（`configCHECK_FOR_STACK_OVERFLOW=1` 监控）。

## 5. 功能清单

| 功能 | 触发方式 | 实现位置 |
|---|---|---|
| 摇杆 4 通道采集/滤波/钳位（1000~2000） | 10ms 周期 | `RC_Analy()`，`src/control/remote.c` |
| AUX1~4 拨动切换（1000↔2000） | 按键边沿 | `key()`，`src/control/remote.c` |
| Roll/Pitch 微调（±5/次，EEPROM 持久化） | 微调按键 | `key()`，`src/control/remote.c` |
| 32 字节帧组包 + NRF 发送 | 10ms 周期 | `NRF_SEND()`，`src/control/remote.c` |
| 上电蜂鸣 + 按键反馈 | 自动 | `init.c` / `key()` |
| 异常长鸣（堆栈溢出/分配失败） | 自动 | `freertos_hooks.c` |

## 6. 关键全局数据（`src/include/all_data.h`）

| 变量 | 类型 | 说明 |
|---|---|---|
| `Remote` | `_st_Remote` | roll/pitch/thr/yaw + AUX1~4（字段顺序 = 帧内发送顺序，勿改动） |
