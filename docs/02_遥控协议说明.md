# 02 遥控器通信协议说明（发送端）

> 本文档定义遥控器（发送端）与飞控端（`Cloud-Drone` 接收端）之间的无线链路参数、32 字节数据帧格式与通道映射契约。
> **任何协议改动必须两端同步更新**，否则会导致无线失联或控制异常。

---

## 1. 无线链路参数（NRF24L01+）

```text
[遥控器发送端 (Cloud-Drone-Remote)] ── 2.4GHz NRF24L01+ ──► [飞控端接收 (Cloud-Drone)]
    单向 TX 模式（只发不收）                                     单向 RX 模式（只收不发）
    32 字节/帧 @ 10ms (100Hz)                                   10ms 轮询接收（5s 失联保护）
```

| 寄存器 / 参数 | 设定值 | 含义 |
| :--- | :--- | :--- |
| `TX_ADDR` / `RX_ADDR_P0` | `{0xE1, 0xE2, 0xE3, 0xE4, 0xE5}` | 5 字节固定通信地址 |
| `RF_CH` | `1`（2401 MHz） | 射频工作频道 |
| `TX_PLOAD_WIDTH` | `32` 字节 | 固定有效载荷长度 |
| `EN_AA` | `0x00` | 关闭自动应答（无 ACK 单向广播式） |
| `EN_RXADDR` | `0x01` | 使能通道 0 |
| `RF_SETUP` | `0x07` | 空中速率 `1 Mbps`，发射功率 `0 dBm` |
| `NCONFIG` | `0x0E` | `PWR_UP=1`，`EN_CRC=1`，`CRCO=1`（16 位 CRC），`PRIM_RX=0`（TX） |

## 2. 32 字节数据帧格式

| 字节偏移 | 长度 | 字段 | 格式 / 取值 |
| :---: | :---: | :--- | :--- |
| `0` | 1 | 帧头 0 | 固定 `0xAA` |
| `1` | 1 | 帧头 1 | 固定 `0xAF` |
| `2` | 1 | 保留 / 功能字 | 固定 `0x03`（接收端不强校验） |
| `3` | 1 | 保留 / 载荷长度 | 固定 `0x1B`（`32 - 5 = 27`） |
| `4..5` | 2 | **Roll** | `uint16_t` 大端，`1000 ~ 2000` |
| `6..7` | 2 | **Pitch** | `uint16_t` 大端，`1000 ~ 2000` |
| `8..9` | 2 | **Throttle** | `uint16_t` 大端，`1000 ~ 2000` |
| `10..11` | 2 | **Yaw** | `uint16_t` 大端，`1000 ~ 2000` |
| `12..13` | 2 | **AUX1** | `uint16_t` 大端，`1000`（关）或 `2000`（开） |
| `14..15` | 2 | **AUX2** | `uint16_t` 大端，`1000`（关）或 `2000`（开） |
| `16..17` | 2 | **AUX3** | `uint16_t` 大端，`1000`（关）或 `2000`（开） |
| `18..19` | 2 | **AUX4** | `uint16_t` 大端，`1000`（关）或 `2000`（开） |
| `20..30` | 11 | 保留区 | 固定填充 `0x00` |
| `31` | 1 | **校验和** | 字节 `0 ~ 30` 无符号逐字节求和后取低 8 位 |

### 组帧核心实现（`src/control/rc_protocol.c`）

```c
void RC_FramePack(uint8_t frame[RC_FRAME_LEN], const _st_Remote *ch)
{
    uint8_t i;
    uint16_t sum = 0u;

    frame[0] = 0xAAu;
    frame[1] = 0xAFu;
    frame[2] = 0x03u;
    frame[3] = 0x1Bu;

    frame_put_be16(frame, 4u, ch->roll);
    frame_put_be16(frame, 6u, ch->pitch);
    frame_put_be16(frame, 8u, ch->thr);
    frame_put_be16(frame, 10u, ch->yaw);
    frame_put_be16(frame, 12u, ch->AUX1);
    frame_put_be16(frame, 14u, ch->AUX2);
    frame_put_be16(frame, 16u, ch->AUX3);
    frame_put_be16(frame, 18u, ch->AUX4);

    for (i = 20u; i < 31u; i++)
        frame[i] = 0u;

    for (i = 0u; i < 31u; i++)
        sum = (uint16_t)(sum + frame[i]);
    frame[31] = (uint8_t)(sum & 0xFFu);
}
```

## 3. 通道映射、滤波与定高油门约束

| 通道 | 范围 | 中位 | 缩放系数 | 飞控端含义 |
| :--- | :---: | :---: | :---: | :--- |
| **Roll** | `1000 ~ 2000` | `1500` | `0.25f` | 横滚目标姿态（叠加 EEPROM Roll 微调，步进 ±5，限幅 ±250） |
| **Pitch** | `1000 ~ 2000` | `1500` | `0.25f` | 俯仰目标姿态（叠加 EEPROM Pitch 微调，步进 ±5，限幅 ±250） |
| **Throttle** | `1000 ~ 1819` | — | **`0.20f`** | 油门控制（定高模式下用于升降速率控制） |
| **Yaw** | `1000 ~ 2000` | `1500` | `0.25f` | 偏航控制（>1820 或 <1180 触发旋转） |
| **AUX1** | `1000 / 2000` | — | 边沿翻转 | 定高模式开关 |
| **AUX2** | `1000 / 2000` | — | 边沿翻转 | 光流定点模式开关（需先开启定高） |
| **AUX3** | `1000 / 2000` | — | 边沿翻转 | 陀螺仪校准触发（飞控未解锁 + 最低油门时有效） |
| **AUX4** | `1000 / 2000` | — | 边沿翻转 | 预留扩展开关 |

### 摇杆信号处理公式
1. **线性映射与微调**：`raw = clamp(1000 + (int32_t)(scale * adc_raw) + trim, 1000, 2000)`。
2. **一阶低通滤波**：首帧直接锁定为 `raw`（避免上电从 0 爬坡）；后续帧 `y = 0.25 * raw + 0.75 * last_y`，再次钳位到 `[1000, 2000]`。

> **重要警告（`RC_THR_SCALE = 0.20f`）**：
> 油门通道严禁改为 `0.25f`！飞控端定高死区上限对应通道值 `1750`：系数为 `0.20f` 时需推至约 92% 行程才触发上升指令；若改为 `0.25f`，73% 常规悬停杆位就会被定高模式误判为持续上升，导致“回中定不住、持续上飞”。

## 4. 联调核对清单（修改前后必查）

1. **射频参数一致**：`RF_CH = 1`、地址 `{0xE1,0xE2,0xE3,0xE4,0xE5}`、32 字节载荷、无 ACK、1Mbps。
2. **帧头与字节序**：帧头 `0xAA 0xAF`，8 通道大端在前、字节 20~30 全零、字节 31 为前 31 字节求和低 8 位。
3. **通道量程与油门缩放**：全部通道严格钳位 `[1000, 2000]`，`RC_THR_SCALE` 保持 `0.20f`。
4. **节拍与失联保护**：发送周期稳定 10ms（100Hz），遥控端看门狗超时 ~2.56s，小于飞控端 5s 失联门限，确保异常重启后空中链路可自动恢复。
