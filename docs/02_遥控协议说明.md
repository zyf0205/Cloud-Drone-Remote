# 02 遥控器通信协议说明（发送端）

> 本文档描述遥控器（发送端）与飞控端（接收端）之间的链路与 32 字节帧格式。
> **必须与飞控端 `docs/02_遥控器通信协议说明.md` 严格保持一致**，任何修改
> （NRF 参数、帧格式、通道含义）都会导致链路失效。

---

## 1. 链路总览

```
[遥控器发送端 (本工程)] -- 2.4GHz NRF24L01 -- [飞控端接收]
   只发不收 (TX 模式)                            只收不发 (RX 模式)
   32字节/帧 @10ms                               10ms 轮询一次
```

- 发送端 NRF24L01 配置（`src/bsp/nrf24l01.c` 的 `TX_Mode()`）：
  - RF 通道：`RF_CH = 1`
  - 地址：`{0xE1,0xE2,0xE3,0xE4,0xE5}`（TX_ADDR 与 RX_ADDR_P0 相同）
  - 载荷宽度：32 字节（`TX_PLOAD_WIDTH`）
  - `EN_AA = 0`：无自动应答（单向广播式）
  - `RF_SETUP = 0x07`：1 Mbps，0 dBm

## 2. 数据帧格式（32 字节）

| 字节偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 1 | 帧头 `0xAA` |
| 1 | 1 | 帧头 `0xAF` |
| 2~3 | 2 | 保留（发送端填充 `0x03, 0x1B`，接收端不校验） |
| 4~5 | 2 | Roll（大端，1000~2000） |
| 6~7 | 2 | Pitch（大端，1000~2000） |
| 8~9 | 2 | Throttle（大端，1000~2000） |
| 10~11 | 2 | Yaw（大端，1000~2000） |
| 12~13 | 2 | AUX1（大端，1000~2000） |
| 14~15 | 2 | AUX2（大端，1000~2000） |
| 16~17 | 2 | AUX3（大端，1000~2000） |
| 18~19 | 2 | AUX4（大端，1000~2000） |
| 20~30 | 11 | 未使用（保留，0） |
| 31 | 1 | 校验和 = 字节 0~30 逐字节求和（截断到 8 位） |

组包逻辑（`src/control/remote.c` 的 `NRF_SEND()`）：

```c
uint8_t tx_data[32] = {0xAA, 0xAF, 0x03, 32-5};   // 帧头 + 保留
for (i = 4; i < 26; i += 2) {
    tx_data[i]   = *((uint8_t*)&Remote + i - 3);  // 高位在前（大端）
    tx_data[i+1] = *((uint8_t*)&Remote + i - 4);  // 低位在后
}
tx_data[31] = 0;
for (i = 0; i < 31; i++)
    tx_data[31] += tx_data[i];                    // 前 31 字节求和
NRF24L01_TxPacket((uint8_t*)&tx_data);            // 发送 32 字节
```

> 依赖 `_st_Remote` 结构体字段顺序（roll,pitch,thr,yaw,AUX1~AUX4，
> 均为 uint16_t），调整结构体时须同步核对帧格式。

## 3. 通道取值范围与含义

| 通道 | 范围 | 中位 | 作用（飞控端） |
|---|---|---|---|
| Roll | 1000~2000 | 1500 | 横滚姿态（0.04°/单位） |
| Pitch | 1000~2000 | 1500 | 俯仰姿态（0.04°/单位） |
| Throttle | 1000~2000 | 1500 | 油门（定高模式控制升降） |
| Yaw | 1000~2000 | 1500 | 偏航（>1820 或 <1180 触发旋转） |
| AUX1 | 1000~2000 | - | 定高开关（边沿切换） |
| AUX2 | 1000~2000 | - | 光流定点开关（需定高开启） |
| AUX3/AUX4 | 1000~2000 | - | 当前仅接收（预留） |

- 摇杆原始值来自 ADC（0~4095），映射公式：`value = 1000 + ADC * 0.25`，
  经一阶低通滤波（新值 25% + 旧值 75%）后钳位到 [1000, 2000]。
- AUX/微调按键：低电平有效，按下一次切换（1000↔2000）；Roll/Pitch 微调 ±5/次。

## 4. 协议约束检查清单（修改后必须逐条核对）

1. NRF：RF_CH=1、地址 `{E1,E2,E3,E4,E5}`、32B 载荷、无 ACK、1Mbps。
2. 帧格式：帧头 AA/AF、通道大端、末字节校验和（前 31 字节求和）。
3. 通道范围 1000~2000，中位 1500。
4. 发送周期 10ms（与飞控端轮询周期一致；飞控端连续 500 次轮询失败约 5s 判定失联）。
