# 02 软件架构

## 1. 分层

| 目录 | 内容 |
|---|---|
| `src/app/` | 任务与 IPC：`app_tasks` / `task_rc` / `task_input` / `task_storage` / `task_buzzer` / `task_monitor` |
| `src/control/` | 遥控业务：`rc_protocol`（纯算法与组帧）/ `remote`（线程安全状态中心） |
| `src/bsp/` | 板级器件：`nrf24l01` / `eeprom` / `key` / `buzzer` |
| `src/driver/` | 底层外设：`adc`（DMA）/ `i2c`（软件）/ `spi`（软件）/ `tim`（TIM3） |
| `src/core/` | 启动与系统：`main` / `init` / `delay` / `sys` |
| `src/include/` | 全局类型：`all_data` / `all_define` |
| `src/FreeRTOS/` | V9.0.0 内核 + RVDS/ARM_CM3 移植 + heap_4 |
| `src/Lib/` | STM32F10x 标准外设库 |
| `src/StartUp/` | 启动文件与 CMSIS |

`rc_protocol.c` 刻意不依赖 STM32 与 FreeRTOS，通道钳位、低通、微调校验、组帧全是纯 C，可以直接拿主机编译器跑单元测试。

## 2. 启动流程

```text
1. Reset_Handler → SystemInit：HSI 8 MHz ÷ 2 × 12 = 48 MHz
2. main()
   2.1  NVIC_PriorityGroupConfig(Group4)
   2.2  RCC_Configuration()：时钟树与基础外设时钟
   2.3  cycleCounterInit()：TIM3 1 kHz
   2.4  DBGMCU_IWDG_STOP：断点调试时冻结看门狗
   2.5  ALL_Init()
          2.5.1  Buzzer_Init + 上电短鸣 200 ms
          2.5.2  IIC_Init()
          2.5.3  NRF24L01_init()：20 次 × 50 ms 在位检测
          2.5.4  test_AT24C02()：20 次重试自检
          2.5.5  ADC1_GPIO_Config + ADC1_Mode_Config
          2.5.6  RC_INIT()：加载微调、初始化 8 路按键
   2.6  App_TasksInit()：创建 2 个队列 + 5 个任务，失败则长鸣停机
   2.7  vTaskStartScheduler()
```

外设自检失败不阻断启动，只置位 `g_boot_fault`，由 `Task_Buzzer` 持续报警。NRF 故障时 `Task_RC_Tx` 跳过发送，EEPROM 故障时微调归零并禁用写入。

## 3. 任务与 IPC

| 通道 | 类型 | 长度 | 用途 |
|---|---|---|---|
| 任务通知 | `xTaskNotify(eSetBits)` | 位掩码 | `Task_RC_Tx` 与 `Task_Input` 向 `Task_Monitor` 报心跳 |
| 存储队列 | `xQueueOverwrite` / `xQueueReceive` | 1 | 微调快照，连按自动合并为最终值 |
| 蜂鸣队列 | `xQueueSend` / `xQueueReceive` | 8 | 按键音与限幅音事件 |

心跳位：`BIT0` = `Task_RC_Tx`，`BIT1` = `Task_Input`。

`Task_Monitor` 是唯一喂狗者，每 500 ms 取走并清空这段时间累计的心跳位，**两位齐全才 `IWDG_ReloadCounter()`**。任一核心任务挂死则停止喂狗，约 2.56 s 后整机复位。

这个复位时间比飞控端 5 s 失联门限短，所以遥控器异常复位后飞控不会误判失联，链路能自行恢复。

## 4. 一帧的生命周期

ADC DMA 在后台持续覆写 `ADC_ConvertedValue[4]`，两个任务各自取快照。

**Task_RC_Tx（10 ms）**

1. `ADC1_ReadSnapshot` 取 4 路原始值
2. 临界区拷 AUX 与微调快照（12 字节，耗时 <2 µs）
3. 4 路摇杆映射 + 微调 + 一阶低通 + 钳位
4. `RC_FramePack` 组 32 B 大端帧与累加和
5. `NRF24L01_TxPacket` 发送（5 ms 软件超时）
6. 上报心跳位

**Task_Input（20 ms）**

1. `Key_Scan` 跑去抖状态机，返回一个事件
2. AUX 键 → `RC_ToggleAux` 在临界区内翻转 1000 / 2000
3. 微调键 → `RC_AdjustTrim` 在临界区内改值，随后投递存储队列与提示音
4. 上报心跳位

AUX 与微调状态由 `Task_Input` 写、`Task_RC_Tx` 读，全部走 `taskENTER_CRITICAL()` 保护。

## 5. 状态机与自愈

**按键去抖**（`key.c`，纯逻辑，与硬件解耦）

| 当前态 | 条件 | 下一态 | 动作 |
|---|---|---|---|
| `IDLE` | 任一键按下 | `DEBOUNCE` | 记录候选键掩码 |
| `DEBOUNCE` | 下一拍候选键仍按下 | `WAIT_RELEASE` | 触发事件 |
| `DEBOUNCE` | 抖动或换了键 | `IDLE` | 清候选 |
| `WAIT_RELEASE` | 全键松开 | `IDLE` | 清候选 |

只有全部按键松开后才接受下一次触发，杜绝长按连发。

**NRF 发送自愈**（`task_rc.c`）

| 发送结果 | 处理 |
|---|---|
| `TX_OK` | 超时计数清零 |
| `TIMEOUT` | 计数 +1；累计 20 次（200 ms）时做一次自检 |
| `MAX_TX` / 其他 | 计数不清零，等待累计到阈值 |

自检结果分两支：`NRF24L01_Check()` 通过则 `TX_Mode()` 重新下发配置尝试自愈；不在位则置 `FAULT_NRF`，停发并报警。

**EEPROM 异步落盘**（`task_storage.c`）

1. 队列醒来，取最新微调快照
2. 只写数值真正变化的轴
3. `vTaskDelay(10 ms)` 等页写周期，期间让出 CPU
4. 回读校验，不一致则置 `FAULT_EEPROM` 并停写

页写期间不阻塞 100 Hz 发包。连续快按微调只落盘最终值，延长擦写寿命。

## 6. 参数速查

| 项目 | 值 |
|---|---|
| 通道量程 | 1000 ~ 2000，中位 1500 |
| 摇杆映射系数 | 0.25 |
| 油门映射系数 | 0.20（满杆约 1819，不可改） |
| 一阶低通系数 | 0.25（新值权重） |
| 微调步进 / 限幅 | 5 / ±250 |
| 帧长 | 32 字节 |
| NRF 发送超时 | 5 ms |
| 连续超时自愈阈值 | 20 次（200 ms） |
| NRF 上电检测 | 20 次 × 50 ms |
| EEPROM 上电自检 | 最多 20 次 |
| EEPROM 页写等待 | 10 ms |
| IWDG | LSI 40 kHz / 128 分频，重载 800 → 约 2.56 s |
| 任务周期 | 发送 10 ms，按键 20 ms，监控 500 ms |

## 7. 推荐阅读顺序

1. `src/include/all_data.h` + `src/app/app_tasks.h` — 数据类型、任务优先级、IPC 接口
2. `src/core/main.c` + `src/core/init.c` — 上电顺序与外设自检
3. `src/control/rc_protocol.c` — 纯算法：钳位、低通、微调校验、组帧
4. `src/control/remote.c` — 线程安全状态中心
5. `src/app/task_rc.c` + `src/app/task_input.c` — 主链路与按键
6. `src/app/task_monitor.c` + `src/app/task_storage.c` + `src/app/task_buzzer.c` — 守护、持久化、声光
7. `src/bsp/nrf24l01.c` + `src/bsp/key.c` — 器件层细节
